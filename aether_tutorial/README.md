# Æther Tutorial

Welcome to the Æther user guide. Follow the steps below to get started with monitoring and analyzing Telegram channels.

## Contents

| Step | Guide | Description |
|------|-------|-------------|
| 1 | [Account Setup](01-account-setup.md) | Register, verify email, and log in |
| 2 | [Telegram Session](02-telegram-session.md) | Connect your Telegram account |
| 3 | [Cases](03-cases.md) | Create and manage monitoring cases |
| 4 | [Analysis](04-analysis.md) | Search messages, run scrapers, monitor jobs |
| 5 | [Agent Chat](05-agent-chat.md) | AI-powered analysis and geo-visualization |
| 6 | [Reports](06-reports.md) | Generate and download case reports |

## Quick Start

```
Register → Verify Email → Connect Telegram → Create Case → Add Channels → Analyze
```

> **Prerequisites:** A Telegram account and valid API credentials (`TG_API_ID`, `TG_API_HASH`) configured in `.env.dev`. See the [main README](../README.md) for setup.
